# Douglas Ebhoman

Technical writer and documentation systems specialist, based in Prague. I build and audit documentation systems for DevTools and SaaS teams: documentation that stays accurate as the product changes, not only on launch day.

Everything here is public and version-controlled, built the way engineers ship code.

- **[MkDocs for Technical Writers](https://douglasebhoman.com/mkdocs-for-technical-writers/)**: from installation to production deployment, written for writers rather than engineers.
